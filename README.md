# Dawnbreakers-Prototype-Demo-03-02-2024-
Host repository for the (03-02-2024) Dawnbreakers demo. Only include the the file necessary for the demo to run. 

Dawnbreakers is a turn-based RPG set in a forgotten and twisted kingdom, shrouded by an everlasting light. 

Dawnbreakers features a unique timeline-based combat system, where you must manipulate your party's and enemy's actions carefully.

Strategize your next move, for it may be your last.
Stagger your enemies. Make. Them. Break.
Gather whatever help you can. They are all you have down here.
Features:

A 7-15 minutes experience, which showcases the baseline mechanics for the game.
2 playable characters.
2 enemies and 1 boss.
Short story with cutscenes.
Warning: There is no audio in the current demo, still working on SFX.
Before you depart, remember this...
THE SUN SHALL NEVER REST
